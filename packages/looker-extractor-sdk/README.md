# looker-extractor-sdk

Plugin SDK for [looker-extractor](https://github.com/luutuankiet/looker-extractor) — the Plugin
Protocol + helpers that plugin authors depend on to build their own Looker entity
extractors without pulling the full extractor core.

> **Phase 1 alpha (v0.1.0a0):** this package ships as a stub. The Plugin Protocol +
> lineage helpers extract from `looker-extractor` core in Phase 2.
